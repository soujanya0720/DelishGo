QuickBite – Online Food Ordering & Delivery Platform

QuickBite is a responsive frontend food ordering website built with HTML, CSS, and JavaScript. It provides an interactive experience for browsing food, searching and filtering dishes, managing a cart, saving favorites, and completing a simulated checkout.

✨ Features
🍕 Browse food menu
🔍 Search food items
🗂️ Filter by categories
🛒 Add and manage cart items
❤️ Save favorite foods
🌙 Dark mode
💾 LocalStorage support
🧾 Checkout form
🔔 Toast notifications
📩 Contact form
📱 Responsive design for desktop, tablet, and mobile
🛠️ Technologies
HTML5 – Structure
CSS3 – Styling and responsive layout
JavaScript (ES6) – Interactivity and DOM manipulation
LocalStorage – Cart and favorites persistence

⚠️ Disclaimer

QuickBite is a frontend-only project created for educational and portfolio purposes. The checkout and payment functionality is simulated and does not process real payments or place real food-delivery orders.
