#  QuickBite – Online Food Ordering & Delivery Platform

QuickBite is a modern and responsive frontend food ordering website that allows users to browse delicious food items, search for dishes, filter food by categories, manage favorites, add products to a shopping cart, and complete a checkout process.

This project is built using **HTML, CSS, and JavaScript** and demonstrates a real-world e-commerce-style frontend experience.

---

##  Live Features

-  Modern Home Page
-  Food Menu
-  Search Food Items
-  Category Filtering
-  Shopping Cart
-  Increase / Decrease Quantity
-  Remove Items from Cart
-  Add / Remove Favorites
-  Dark Mode
-  LocalStorage
-  Checkout Form
-  Order Success Notification
-  Contact Form
-  Success Toast Notifications
-  Fully Responsive Design
-  Mobile Navigation Menu
